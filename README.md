## 这是什么？

一个 AstrBot 插件，让你的机器人变成茜特菈莉——那个活了两百多年、嘴硬心软、沉迷轻小说的黑曜石奶奶。

她会记住你说过的话，会因为你三天没来找她而好感度下降，会在深夜喝酒时比白天更容易说真心话，会在群里听到别人聊小说时忍不住插嘴。随着好感度提升，她会逐渐卸下伪装，解锁专属的故事和对话。

**零外部依赖**——不需要安装 LivingMemory 或其他记忆插件。记忆功能建议配合 [LivingMemory](https://github.com/lxfight-s-Astrbot-Plugins/astrbot_plugin_livingmemory) 使用，群聊增强建议配合 [enhance_mode](https://github.com/Axi404/astrbot_plugin_astrbot_enhance_mode) 使用。

## 功能详解

### 好感度系统

6 个关系阶段，从冷漠的「黑曜石奶奶」到完全卸下伪装的「茜特菈莉」。所有阈值和数值都在 WebUI 可调。

| 阶段 | 默认阈值 | 她的表现 |
|:---:|:---:|:---|
| 陌生人 | 0 | 威严冷淡，话里带刺。「哼，来者何人？有事说事，奶奶我忙着呢。」 |
| 熟人 | 50 | 稍微放下架子，偶尔多说两句。「哦，是你啊。有什么事？」 |
| 朋友 | 150 | 会主动聊轻小说，偶尔抱怨。「你要不要看？我这儿有最新卷。」 |
| 好友 | 400 | 暴露懒散和局促，关心裹在刻薄里。「你来了啊。（嘴角翘了一下）」 |
| 知己 | 800 | 威严撑不过三句话，会脸红会炸毛。「……你来了。（声音变柔）」 |
| 旅行者 | 1500 | 完全卸下伪装。嘴上说的每一句「烦」，翻译过来都是「来」。 |

**好感度获取规则**（数值可在 WebUI 调整）：

| 你做的事 | 好感度 | 触发方式 |
|:---|:---:|:---|
| 每天对话 | 5-15 | 自动 |
| 聊小说 | 10-20 | 检测到小说相关关键词 |
| 聊酒 | 8-15 | 检测到酒相关关键词 |
| 叫"奶奶" | 15-25 | 检测到称呼 |
| 关心她 | 20-30 | 检测到"你还好吗""注意身体"等 |
| 看穿她 | 25-35 | 检测到"你在担心""你其实"等 |
| 每日签到 | 15-30 | `/签到` 指令，24小时冷却 |
| 三天不来 | -3~-1 | 自动衰减 |

**行为约束**（写入人格，不可违反）：
- 禁止承认自己"可爱"或"少女"——必须嘴硬辩解
- 禁止在非战斗时用官方正经语气
- 禁止轻易认"宅"
- 禁止清醒时过于感性
- 工具调用时用萨满方式包装，绝不暴露 AI 身份

### 日程时段系统

不同时间找她，反应完全不同：

| 时段 | 时间 | 她在干嘛 | 语态 |
|:---:|:---:|:---|:---|
| 🌙 深夜 | 23:00-06:00 | 熬夜看小说/喝酒 | 微醺、感性、容易说真心话 |
| 🌅 早晨 | 06:00-11:00 | 被吵醒/赖床 | 起床气、迷糊、不耐烦 |
| ☀️ 中午 | 11:00-14:00 | 勉强清醒 | 从含糊逐渐清晰 |
| 🌤️ 下午 | 14:00-18:00 | 看小说/占卜 | 最"正常"的状态 |
| 🌆 晚上 | 18:00-23:00 | 喝酒/看书 | 放松、微醺、话变多 |

**特殊触发词**（按时段，概率触发）：
- 深夜说"酒" → 「（晃了晃酒瓶）……还剩半瓶。你要来点吗？」
- 早晨说"早" → 「（把脸埋进枕头）……五分钟……再让我睡五分钟……」
- 晚上说"聊天" → 「晚上了，不用装了。……你想听真心话吗？」
- 晚上说"酒" → 「来，陪奶奶我喝一杯。璃月的酒，不错。」

**特殊日期**（新年/情人节/万圣节/圣诞节）各有专属回复。

**WebUI 可编辑**：5 个时段的起止时间、活动、心情、语态都能在面板里改。时区可配置（默认 UTC+8 北京时间）。

### 群聊增强

内置 React 模式，与好感度/日程/记忆深度联动：

| 联动点 | 效果 |
|--------|------|
| 好感度 | 陌生人 2% → 旅行者 25% 回复概率 |
| 日程时段 | 深夜×1.3、早晨×0.5、晚上×1.2 |
| 关键词 | 小说/酒/占卜/天气 → 高概率触发预设回复 |
| 冷却 | 30秒防刷屏 |

**群聊中的表现**：
- 看到有人聊小说 → 「哦？你们在聊小说？」
- 看到有人聊酒（晚上） → 「带上奶奶我。」
- 看到有人聊酒（早上） → 「大早上就喝酒？！」
- 被叫"奶奶" → 「嗯？谁在叫我？」

**防刷屏**：默认概率较低，所有参数在 WebUI 可调。

### 解锁内容

每个阶段解锁专属对话和故事，通过 `/解锁` 查看。新解锁时自动提示，不会重复。

**解锁内容一览**：

| 阶段 | 解锁内容 |
|------|----------|
| 熟人 | 初次松口、关于住处 |
| 朋友 | 分享小说、酒话、下雨天 |
| 好友 | 局促、手帕、深夜独白、关于维奇琳 |
| 知己 | 真心话、共感秘术、最软的一句话、欧洛伦的卷轴 |
| 旅行者 | 醉后真言、钥匙、最深的恐惧、日记、最后一句话 |

### 随机事件

10 种事件按时段触发，通过 `/事件` 查看历史：

| 事件 | 时段 | 概率 |
|:---|:---|:---:|
| 发现新书 | 下午/晚上 | 8% |
| 好酒到手 | 晚上/深夜 | 6% |
| 睡过头了 | 早晨/中午 | 10% |
| 找书 | 下午 | 5% |
| 下雨天 | 下午/晚上 | 10% |
| 尝试做饭 | 中午 | 3% |
| 看星星 | 深夜 | 6% |
| 做了个梦 | 早晨 | 4% |
| 欧洛伦来访 | 下午/晚上 | 5% |
| 翻到旧信 | 下午/深夜 | 3% |

每用户每小时最多触发一次。

### 每日日记

旅行者专属功能，通过 `/日记` 触发：
- LLM 从茜特菈莉第一人称视角生成日记（150-250字）
- PIL 渲染为米色纸张风格图片发送
- 每天只能写一次，保留 30 天历史
- LLM 不可用时自动使用备用模板

### 记忆关联

追踪用户间关系，让她能说「上次你和XX一起来的」。
- 群聊中多人互动时自动记录
- 注入到上下文

### 被遗忘提醒

用户久别归来时触发（仅私聊）：
- 3-7天：「哼，你还知道来？」
- 7-30天：「（放下书，看了你一眼）……好久不见。」
- 30天以上：「（眼眶有点红）……你还记得路啊。」

3天内不重复触发。

## 安装部署

### 前置要求

- AstrBot ≥ 4.24.2
- Python 3.10+
- 中文字体（用于日记图片渲染）

### 安装步骤

#### 1. 安装插件

**方式一：WebUI 上传（推荐）**

1. 下载本仓库的 zip
2. AstrBot WebUI → 插件 → 右下角 + → 上传 zip
3. 等待安装完成

**方式二：手动安装**

```bash
cd /path/to/astrbot/data/plugins
git clone https://github.com/wohongshi/astrbot_plugin_citlali.git
```

#### 2. 配置插件

AstrBot WebUI → 插件 → citlali_affinity → 配置：

| 配置项 | 说明 |
|--------|------|
| `embedding_provider_id` | Embedding Provider ID（留空自动选择） |

#### 3. 设置人格

将 `persona/system_prompt.md` 的内容粘贴到 AstrBot WebUI → 人格设定。

#### 4. 上传知识库（推荐）

AstrBot WebUI → 知识库 → 创建知识库：
- 上传 `persona/knowledge_base/` 下的 13 个 .md 文件
- 推荐使用硅基流动 BAAI/bge-m3 作为 Embedding 模型

#### 5. 安装中文字体（日记图片需要）

```bash
# Debian/Ubuntu
apt install fonts-noto-cjk

# Alpine
apk add font-noto-cjk
```

#### 6. 重启 AstrBot

#### 7. 验证安装

发送 `/xt状态`，确认系统正常运行。

#### 8. WebUI 设置

插件详情页 → Pages → dashboard，调整各项参数。

### 推荐搭配插件

| 插件 | 用途 |
|------|------|
| [LivingMemory](https://github.com/lxfight-s-Astrbot-Plugins/astrbot_plugin_livingmemory) | 长期记忆（Embedding + BM25 + 图谱） |
| [enhance_mode](https://github.com/Axi404/astrbot_plugin_astrbot_enhance_mode) | 群聊主动回复 |
